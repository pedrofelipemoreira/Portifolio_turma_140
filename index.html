Formação em

FRONT-

TRF / 140 / DEV

O curso Transforme-se Front-end apresenta os fundamentos necessários para a criação de páginas e interfaces digitais modernas.

A formação combina tecnologia, design, lógica e criatividade. Os estudantes aprendem a estruturar conteúdos, estilizar interfaces e implementar comportamentos interativos.

Perfil profissional desenvolvido

  • Desenvolver páginas utilizando HTML e CSS.
  • Criar interfaces adaptáveis para computadores e celulares.
  • Aplicar fundamentos de lógica de programação.
  • Implementar interatividade com JavaScript.
  • Trabalhar de maneira colaborativa em projetos.
  • Organizar e apresentar um portfólio profissional.
